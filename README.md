# Atena Growth Assessment — Mock Homepage

## Purpose
This local prototype demonstrates one simple technical change for Task 3: a conversion-focused hero / landing experience with clearer calls to action, mobile responsiveness, trust messaging, simple "How to Play" guidance, and mock CTA event tracking.

## Important
- This is NOT Atena's live website.
- No live play, payment, database or customer data is used.
- All interaction is illustrative.
- The "Play Now" button only records a mock analytics event.

## Files
- index.html
- styles.css
- script.js

## How to run locally
Open index.html directly in a browser, or run a simple local server.

## What the prototype demonstrates
- Clearer above-the-fold value proposition
- Strong primary and secondary CTAs
- Mobile-first responsive layout
- Trust / responsible-play cues
- Short three-step "How to Play" journey
- Semantic headings and meta description for SEO readiness
- Basic event tracking for conversion measurement

## Assessment explanation
I did not rebuild the live Atena platform. I created a conversion-focused homepage prototype to demonstrate one practical improvement: a clearer path from landing to play. The mock also tracks CTA clicks so the change is measurable. In production, the same approach would be connected to approved Atena routes and analytics events such as registration_start, registration_complete and first_play.
